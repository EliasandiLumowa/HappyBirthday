# 🎂 Happy 25th Birthday Alda! ✨

Website ucapan selamat ulang tahun ke-25 untuk **Alda**, bertemakan **Baby Blue Ceria** & aksen **Doraemon** yang lucu dan interaktif.

---

## 🌟 Fitur Utama

1. **Halaman Awal - Realtime Countdown (Menuju 14 November 00:00)**:
   - Hitung mundur live otomatis menghitung hari, jam, menit, dan detik.
   - Karakter Doraemon dengan **baling-baling bambu berputar** di atas kepala.
   - Tombol interaktif *"Ketuk Lonceng Buat Doa Baik"* yang menghitung setiap doa yang dikirim.
   - Tombol **"⚡ Buka Kejutan Langsung"** untuk mengetes atau melihat efek kejutan secara instan tanpa perlu menunggu tengah malam.

2. **Efek Surprise Boom (Tepat Pukul 00:00 atau Saat Dibuka)**:
   - Efek ledakan visual, getaran layar (*screen shake*), dan kilatan cahaya.
   - Hamburan **perhiasan & pernak-pernik lucu** (💎, 💍, 🔔, 🍰, 🌸, 💖, ⭐, 🎀).
   - Hujan konfeti warna-warni (*canvas confetti shower*).
   - Efek suara kejutan (*synthesized Web Audio*) yang ceria.

3. **Surat Ucapan Ulang Tahun yang Hangat**:
   - Desain amplop/surat estetik dengan *washi tape* dan perangko lonceng Doraemon.
   - Memuat kalimat ucapan lengkap sesuai permintaan:
     - Doa usia ke-25, kesehatan, kesabaran, kelancaran proses, dsb.
     - Permintaan maaf yang tulus dan menyentuh hati.
     - Petunjuk interaktif untuk scroll ke bawah menuju kue ulang tahun.

4. **Kue Ulang Tahun Online & Tiup Lilin (Make A Wish First and Blow It)**:
   - Animasi kue 2 tingkat warna *baby blue* dengan krim meleleh (*dripping icing*), buah stroberi, ceri, dan meses warna-warni.
   - Lilin angka **25** dengan animasi lidah api yang menyala dan berkedip realistis.
   - **Fitur Tiup Lilin Ganda (Blow & Touch)**:
     - 🎙️ **Tiup via Mikrofon**: Mendeteksi tiupan angin ke mic smartphone / laptop secara realtime disertai meteran kekuatan tiupan.
     - 👆 **Sentuh / Klik Lilin**: Cukup sentuh api atau tekan tombol untuk memadamkan lilin sebagai alternatif yang 100% aman dan praktis.
   - Saat lilin padam:
     - Asap mengepul naik dari sumbu lilin.
     - Suara tiupan dan kembang api/chime kemenangan.
     - Kartu ucapan *"YAAAY! WISH KAMU TERKABUL!"* muncul dengan doa restu.
     - Tombol *"🔄 Nyalakan Lilin Lagi"* jika ingin meniup ulang.

5. **Kantong Ajaib Doraemon (Lokasi Kado)**:
   - Animasi kantong 4D dan kotak kado 3D interaktif.
   - Tombol langsung terhubung ke **WhatsApp** dengan pesan otomatis untuk Alda membagikan lokasi/alamat pengiriman kado ulang tahun.

6. **Musik Latar Belakang (BGM)**:
   - Synthesizer lagu *Happy Birthday to You* dengan nada kotak musik lofi yang lembut dan menenangkan.
   - Tombol mengambang (Floating Pill) di pojok kanan bawah untuk Play / Pause musik kapan saja.
   - 100% mandiri (*zero external audio dependency*), tidak akan gagal karena masalah CORS atau koneksi.

## 🚀 Panduan Hosting di GitHub Pages

Repository tujuan Anda:
`https://github.com/EliasandiLumowa/semangatya_alda`

### Langkah 1: Push File ke GitHub
Buka terminal / PowerShell dan jalankan:
```bash
git add .
git commit -m "Happy 25th Birthday Alda - Baby Blue & Doraemon Website"
git push origin main
```

### Langkah 2: Aktifkan GitHub Pages
1. Buka browser dan pergi ke halaman repository:
   **https://github.com/EliasandiLumowa/semangatya_alda**
2. Klik tab **Settings** (ikon gerigi di atas).
3. Di menu sebelah kiri, klik **Pages**.
4. Di bagian **Build and deployment**:
   - **Source**: Pilih `Deploy from a branch`
   - **Branch**: Pilih `main`
   - **Folder**:
     - Jika file `index.html` berada di root repository, pilih `/ (root)`.
     - Jika file berada di folder `Birthday`, pilih `/root` atau sesuaikan.
5. Klik tombol **Save**.

Dalam 1–2 menit, link website akan aktif di:
👉 `https://eliasandilumowa.github.io/semangatya_alda/` (atau `.../Birthday/`)
